## Objective
To create an interactive dashboard that presents supermarket sales performance through key performance indicators (KPIs), charts, and filters.

## Dashboard Features
- Total Revenue
- Total Quantity Sold
- Average Customer Rating
- Total Transactions
- Sales by Product Line

- Payment Method Distribution
- Daily Sales Analysis by Weekday

- Product Line
- Payment Method
- Date Range
