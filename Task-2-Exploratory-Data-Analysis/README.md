# SWYNEX Internship – Task 2: Exploratory Data Analysis (EDA)

## 1. Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Supermarket Sales dataset using Python. The objective is to identify sales patterns, customer payment preferences, product performance, and branch-wise revenue through data analysis and visualization.

## 2. Dataset Information
- **Dataset:** Supermarket Sales
- **Total Records:** 1,000
- **Total Columns:** 18 (including the additional `day` feature created during analysis)
- **Missing Values:** 0
- **Duplicate Records:** 0

## 3. Tools and Technologies
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## 4. Data Analysis and Visualizations

### 1. Total Sales by Product Line
This bar chart compares total revenue across different product lines.

**Key Finding:** Food and Beverages generated the highest revenue.

### 2. Total Sales by Branch
This chart compares the total revenue generated by different supermarket branches.

**Key Finding:** Branch C recorded the highest total sales.

### 3. Payment Method Distribution
This pie chart shows the distribution of Cash, Credit Card, and Ewallet payments.

**Key Finding:** Ewallet was the most frequently used payment method.

### 4. Sales Distribution
This histogram displays the distribution of transaction amounts.

**Key Finding:** The sales distribution is right-skewed, indicating that some transactions had considerably higher values.

### 5. Daily Sales Analysis
This chart compares total sales across different days of the week.

**Key Finding:** Saturday recorded the highest total sales.

## 7. Key Insights
1. Food and Beverages was the highest-revenue product line.
2. Branch C generated the highest revenue.
3. Ewallet was the most frequently used payment method.
4. Saturday recorded the highest sales.
5. No missing values or duplicate records were found.
6. Nine potential outliers were identified using the IQR method.
