# SWYNEX Internship – Task 2: Exploratory Data Analysis (EDA)

## Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on the Supermarket Sales dataset using Python. The main objective is to understand sales patterns, customer payment preferences, product performance, and branch-wise revenue through data analysis and visualization.

## Dataset Information
- **Dataset:** Supermarket Sales
- **Total Records:** 1,000
- **Total Columns:** 18 (including the additional day feature created during analysis)
- **Missing Values:** 0
- **Duplicate Records:** 0

## Tools and Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Data Analysis and Visualizations

Five visualizations were created to understand different aspects of the supermarket sales data.

### 1. Total Sales by Product Line
This bar chart compares the total revenue generated by different product lines. It helps identify the best-performing product category.

**Key Finding:** Food and Beverages generated the highest revenue.

### 2. Total Sales by Branch
This chart compares the total revenue generated by different supermarket branches.

**Key Finding:** Branch C recorded the highest total sales.

### 3. Payment Method Distribution
This pie chart displays the distribution of customer payment methods, including Cash, Credit Card, and Ewallet.

**Key Finding:** Ewallet was the most frequently used payment method.

### 4. Sales Distribution
This histogram shows how transaction amounts are distributed across the dataset.

**Key Finding:** The sales distribution is right-skewed, indicating that some transactions have considerably higher values.

### 5. Daily Sales Analysis
This chart compares total sales across different days of the week.

**Key Finding:** Saturday recorded the highest total sales.

## Key Insights
1. Food and Beverages was the highest-revenue product line.
2. Branch C generated the highest revenue among the branches.
3. Ewallet was the most popular payment method.
4. Saturday recorded the highest sales.
5. The dataset contained no missing values or duplicate records.
6. Nine potential outliers were identified using the IQR method.
