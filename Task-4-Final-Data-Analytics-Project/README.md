# Task 4: Final Data Analytics Project

## Project Title
**Supermarket Sales Data Analytics – A Complete Case Study**

## Internship Details
- **Organization:** SWYNEX Technologies
- **Internship:** Data Analyst Internship
- **Project:** Final Data Analytics Project
- **Tools:** Python, Pandas, Matplotlib, Seaborn, Google Looker Studio

## 1. Problem Statement
The objective of this project is to analyze supermarket sales data to understand sales performance, customer purchasing patterns, product performance, and branch-wise revenue. The analysis aims to identify meaningful business insights that can support better decision-making.

## 2. Dataset Information
- **Dataset:** Supermarket Sales
- **Total Records:** 1,000
- **Original Columns:** 17
- **Data Type:** Structured CSV dataset

## 3. Data Cleaning and Preparation
The dataset was cleaned and prepared using Python and Pandas.

Cleaning activities included:
- Checking missing values
- Identifying duplicate records
- Checking data types
- Preparing the dataset for analysis
- Saving the cleaned dataset

## 4. Exploratory Data Analysis
Exploratory Data Analysis was performed to understand the dataset and identify patterns.

Analysis included:
- Summary statistics
- Product-line sales analysis
- Branch-wise sales analysis
- Payment method distribution
- Daily sales analysis
- Outlier detection using the IQR method

## 5. Interactive Dashboard
An interactive supermarket sales dashboard was developed using Google Looker Studio.

**Dashboard Link:**  
https://datastudio.google.com/reporting/13097cba-a033-4857-b173-aba7cbc8e508

Dashboard features:
- Total Revenue
- Total Quantity Sold
- Average Customer Rating
- Total Transactions
- Sales by Product Line
- Sales by Branch
- Payment Method Distribution
- Daily Sales Analysis
- Interactive Filters

## 6. Key Business Insights
- Food and Beverages generated the highest revenue among product lines.
- Branch C recorded the highest sales.
- E-wallet was the most-used payment method.
- Saturday recorded the highest sales among weekdays.

## 7. Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Looker Studio
- GitHub

## 8. Conclusion
This project demonstrates the complete data analytics process, from data cleaning and exploratory analysis to interactive dashboard development. The findings help understand supermarket sales performance and demonstrate how data analysis can support business decision-making.
